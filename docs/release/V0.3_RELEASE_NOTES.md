# V0.3 Release Notes

## Summary

V0.3 turns LabourCompressor into an automatic segmentation-first workflow. The system can now download source videos, split long videos into valid `3-30s` clips, send only accepted clips into native video-level tagging, write spreadsheet results, and archive by the unique `内容题材` path.

This release keeps the V0.2 manual `AfterEdit` workflow available, but the main V0.3 path is full automation from spreadsheet import through segmented clip tagging.

## Included Capabilities

- Automatic segmentation before tagging.
- PySceneDetect-backed scene detection with project-local installation through `npm run setup:mac`.
- `standard_ad`, `fast_cut`, and `conservative` segmentation profiles.
- Duration governance for `3-30s` clips, with `5-30s` as the preferred practical target.
- Forced splitting for detected segments longer than 30 seconds.
- Consecutive fast-cut short shots are merged into valid clip groups instead of being routed to problem clips individually.
- PySceneDetect 0.7 CSV metadata rows are parsed correctly.
- Problem clips are isolated under `ProblemClips` for three categories:
  - `无法满足 3-30s`
  - `导出失败`
  - `检测结果异常`
- Accepted clips are written into `AfterEdit` and named with ordered suffixes such as `_01`, `_02`.
- Original downloaded full videos remain in the download cache and do not enter tagging or archive.
- The Web UI exposes automatic segmentation controls and keeps the manual edit gate available for V0.2-style operation.
- A generated Apple Silicon macOS launcher app starts the local Web UI by double-clicking `dist/LabourCompressor.app`.
- Setup now installs a local PySceneDetect virtual environment under `.tools/` instead of relying on a Homebrew formula.

## Verification Status

The V0.3 release candidate was verified with:

```bash
npm run test:taxonomy-domain
```

The latest verification passed `208` unit and integration tests covering archive, CLI, core records, desktop launcher generation, download, governance, media adapters, retrieval, segmentation, spreadsheet handling, tagging, taxonomy, Web UI, and phase integration paths.

Manual V0.3 testing also passed after clearing local runtime data and rerunning the workflow through the Web UI.

## Security And Local Exclusions

The release intentionally excludes:

- `*.local.json`
- real API keys
- cookies and browser session exports
- OAuth secrets and tokens
- `.cache/`
- `.runtime-state/`
- `.runtime-uploads/`
- `.tools/`
- `node_modules/`
- downloaded or edited video files
- user spreadsheets
- `视频数据下载缓存/`
- `视频数据采集总表.xlsx`
- generated local app bundles under `dist/`

## Known Limits

- V0.3 segmentation is still rule-based. It does not perform full semantic story analysis.
- Download reliability depends on `yt-dlp`, `ffmpeg`, local network conditions, platform policy, account state, and cookie freshness.
- Platform login automation and risk-control bypass are not included.
- `Numbers` remains a compatibility path; `xlsx` is still the complete standard format.
- Model quality, speed, and rate limits depend on the selected provider account and quota.
- The generated macOS launcher targets Apple Silicon Macs only.
