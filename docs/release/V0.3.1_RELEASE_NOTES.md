# V0.3.1 Release Notes

## 摘要

V0.3.1 是 Windows 本地 Web 适配版本。该版本保留 V0.3 自动分割主线，并新增 Windows 依赖安装脚本、Windows 本地工具路径解析、Windows 文件选择支持，以及安装后可双击打开的本地应用入口。

## 主要变化

- 新增 `npm run setup:windows`，用于检查 Node.js、npm、Python、`yt-dlp`、`ffmpeg` 和 PySceneDetect。
- Windows setup 优先使用 `winget` 安装系统依赖；没有 `winget` 时给出手动安装提示。
- PySceneDetect 在 Windows 下安装到项目本地 `.tools/scenedetect-venv/`。
- 新增 `npm run launcher:windows`，生成 Windows 本地启动入口：
  - `dist/LabourCompressor.vbs`：推荐双击入口，隐藏 PowerShell 窗口；
  - `dist/LabourCompressor.cmd`：排错入口，保留命令行窗口；
  - `dist/LabourCompressor.ps1`：底层 PowerShell 启动脚本。
- Web UI 本地文件/文件夹选择新增 Windows PowerShell/COM 分支，macOS 继续使用 `osascript`。
- `yt-dlp`、`ffmpeg`、`ffprobe` 和 PySceneDetect 的解析逻辑支持 Windows `.exe`、`.cmd`、`.bat` 和项目本地 `.tools` 路径。
- Preflight 增加 `ffprobe` 与 PySceneDetect 检查。
- README 已改为中文，并补充 Windows 安装、启动和排错说明。

## 验证状态

本版本在当前开发环境中执行了：

```bash
npm run test:taxonomy-domain
```

验证通过 `216` 个单元和集成测试，覆盖 archive、CLI、core records、desktop launcher、download、governance、media adapters、retrieval、segmentation、spreadsheet、tagging、taxonomy、Web UI 和阶段集成路径。

还验证了 Windows launcher 生成命令：

```bash
node scripts/create-windows-launcher.ts --output-root /tmp/labour-windows-launcher-test --project-root <project-root>
```

该命令会生成 `.vbs`、`.cmd` 和 `.ps1` 三个启动文件。

## 注意事项

- 当前 Windows 支持已由可模拟的平台分支测试覆盖；正式 Windows 部署前仍建议在真实 Windows 10/11 机器上执行一次手工验收。
- Windows 双击入口本质上启动本地 Web UI 服务并打开浏览器，不是 Electron 应用或安装器。
- 若 `dist/LabourCompressor.vbs` 双击后没有反应，请改用 `dist/LabourCompressor.cmd` 查看错误输出。
