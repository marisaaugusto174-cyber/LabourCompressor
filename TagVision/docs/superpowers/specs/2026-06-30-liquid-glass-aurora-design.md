# TagVision Liquid Glass + Aurora 界面设计

## 目标

在不改变 TagVision 检视功能和数据流的前提下，将首页与详情页统一改造为白色主调的 Liquid Glass 界面，并使用静态蓝粉 Aurora 作为底层背景。界面保持极简，删除非必要描述性文字，视频预览和播放器画面不受任何颜色覆盖。

## 视觉原则

- 主色为珍珠白和冷白色；蓝色与粉色仅作为 Aurora 背景和轻微状态倾向。
- Aurora 是连续、静态的大面积光场，不使用随机圆形光晕、飞线、涟漪、粒子或动画。
- 所有功能容器使用统一的白色 Liquid Glass 材质：半透明白色填充、背景模糊、轻度饱和、白色高光描边、柔和阴影和克制的内高光。
- 视频缩略图和播放器画面保持原始色彩。玻璃效果只用于视频外框、控制层和内容信息层。
- 按钮使用中性白色玻璃，不直接填充幻彩渐变。主操作仅允许轻微蓝色文字、边框或冷色表面倾向。
- 标签文本保持高对比度，不能因为透明度、Aurora 或折射高光而降低可读性。

## 首页

首页采用极简信息结构：

1. 顶部仅显示 TagVision 标识和“入口”；
2. 单行目录输入、选择目录和扫描按钮；
3. 四个扫描统计卡；
4. 加载更多按钮；
5. 视频检视卡片网格；
6. 诊断区只在存在异常或运行错误时显示。

删除页面副标题、版本说明、能力标签、“检视来源”“多视频预览”等区块标题及解释性段落。空状态只保留一句必要操作提示。

视频卡片的外框和正文使用 Liquid Glass；缩略图区域完全不透明并保持原色。序号与媒体格式徽标使用叠加在视频上的深色透明玻璃，以确保任何画面上都可读。标签芯片使用浅白玻璃，不能增加额外描述。

## 详情页

详情页保持视口内三行结构：玻璃页头、主体、居中玻璃序号。主体继续按视频画幅自适应播放器与标签区域宽度。

- 页头、播放器外框、右侧标签面板、accepted 编辑器和底部序号采用同一 Liquid Glass 材质。
- 播放器内部保持深色承载层和原始视频画面；Plyr 控件保持可读，不叠加 Aurora 色彩。
- 标签摘要、完整标签卡片、accepted 路径和操作按钮使用高对比浅色玻璃。
- accepted 路径继续完整换行显示，不允许省略号。
- 标签数量过多时只允许右侧面板内部滚动，外层页面和播放器保持固定。

## 材质实现

CSS 使用静态多层 `radial-gradient` 构成蓝粉 Aurora，并通过 `background-attachment: fixed` 保持稳定。Liquid Glass 使用共享样式变量和组件类统一管理：

- 半透明白色线性表面；
- `backdrop-filter: blur(...) saturate(...)`；
- 低透明白色边框；
- 外部柔和阴影；
- 顶部内高光和底部冷色内阴影；
- 不阻挡点击的边缘高光伪元素。

对不支持 `backdrop-filter` 的浏览器，组件以较高不透明度白色背景回退，不能变成透明不可读状态。

## 功能与数据兼容

目录扫描、排序、缩略图加载、Plyr 播放、键盘快捷键、画幅自适应、证据覆盖层、accepted 编辑和保存接口均保持不变。本次不新增依赖，不修改后端数据结构。

诊断数据仍然生成；正常状态下诊断区隐藏，存在未配对、孤儿 JSON、无效 JSON 或动作错误时显示。

## 测试与验收

- 单元测试确认非必要说明文字和旧区块标题已删除；
- 单元测试确认正常扫描时诊断区隐藏，存在异常时显示；
- CSS 测试确认静态蓝粉 Aurora、统一玻璃材质、`backdrop-filter` 和白色回退存在；
- 1920×1080 实测首页信息密度、四列卡片和静态背景；
- 实测视频缩略图、播放器画面没有颜色遮罩；
- 实测横屏、竖屏和方形详情布局，标签与 accepted 路径可读；
- 实测方向键、空格、Esc、Plyr 控件和 accepted 保存；
- 运行完整测试、类型检查和 macOS 打包。

## 非目标

本次不实现动态 Aurora、随机光晕、飞线、涟漪、粒子、WebGL 或 Canvas 背景，也不重新设计播放器功能和标签数据结构。
