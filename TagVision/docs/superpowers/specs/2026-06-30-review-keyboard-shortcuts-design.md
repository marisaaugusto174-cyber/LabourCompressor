# TagVision 检视快捷键设计

## 目标

为视频详情检视增加高频键盘操作，减少鼠标移动和点击，提高连续检视效率，同时避免影响页面表单输入和浏览器默认操作。

## 快捷键

详情弹窗打开时启用以下按键：

- `←`：打开上一个视频；当前已是第一条时不操作。
- `→`：打开下一个视频；当前已是最后一条时不操作。
- `空格`：切换当前视频的播放与暂停，并阻止页面滚动或按钮默认点击。
- `Esc`：关闭详情弹窗，沿用现有行为。

方向键始终用于视频翻页，不保留播放器原生的快退和快进行为。翻页后新视频保持暂停，不自动播放。

## 触发条件与冲突处理

快捷键只在详情弹窗打开时生效。详情关闭时，不拦截任何上述按键。

当焦点位于 `input`、`select`、`textarea` 或可编辑区域时，不处理快捷键，保证表单编辑不受影响。普通按钮获得焦点时仍使用检视快捷键；其中空格必须阻止按钮的默认点击行为。

忽略按键自动重复事件，避免长按空格反复切换播放状态，或长按方向键一次跨过多个视频。

## 页面提示

在详情弹窗底部导航区域显示简短提示：

`← 上一个　空格 播放/暂停　→ 下一个　Esc 关闭`

提示只说明现有快捷键，不增加设置面板或自定义键位功能。

## 实现方式

继续使用现有的全局 `keydown` 监听器，将详情快捷键集中交给一个处理函数。处理函数负责：

1. 判断详情是否打开；
2. 排除可编辑控件和自动重复事件；
3. 根据按键调用现有的 `openDetail()`、`closeDetail()`，或切换 `detailVideo` 的播放状态；
4. 只在实际识别到快捷键时调用 `preventDefault()`。

不改变后端接口、扫描排序、视频数据结构或检视保存逻辑。

## 测试与验收

自动化测试需要覆盖：

- 页面展示快捷键提示；
- 详情打开时四种快捷键映射正确；
- 详情关闭、可编辑控件聚焦或按键自动重复时不触发；
- 第一条和最后一条的翻页边界不会越界；
- 空格在视频播放与暂停之间切换，并阻止默认行为；
- 方向键翻页后新视频保持暂停。

重新生成 macOS 包并重启本地服务后，在实际检视页面中验证键盘操作。
