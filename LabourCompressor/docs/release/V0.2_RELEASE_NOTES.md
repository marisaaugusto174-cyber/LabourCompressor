# V0.2 Release Notes

## Summary

V0.2 establishes the first private GitHub-ready baseline for LabourCompressor. The release focuses on a local Web UI, spreadsheet-driven task execution, Bilibili-oriented download validation, manual edit handoff, native video-level model tagging, structured spreadsheet writeback, and archive placement by a unique `内容题材` terminal path.

This release is intended for private repository use. It excludes real credentials, cookies, downloaded media, user spreadsheets, runtime cache, and local task state.

## Included Capabilities

- Local Web UI for task setup, preflight, task status, and result review.
- CLI and local service entrypoints for the same pipeline.
- Spreadsheet import and writeback with standard columns:
  - `URL`
  - `采集人`
  - `归档状态`
  - `一级标签`
  - `二级标签`
  - `三级标签`
  - `四级标签`
  - `归档路径`
  - `归档文件名`
- Program master spreadsheet support and per-task result spreadsheet generation.
- `AfterEdit` manual editing gate and post-edit record spreadsheet generation.
- Standardized download file naming for stable file reads.
- Video tagging cache before model input:
  - `360p`
  - original frame rate
  - `650 kbps` video
  - `AAC 64 kbps` audio
  - hash-based reuse
- Native video-level model tagging, not frame-extraction tagging.
- Curated video model profiles:
  - `Qwen 3.6 Flash`
  - `Qwen 3.6 Plus`
  - `Qwen 3.5 Plus`
  - `Gemini 3 Flash Thinking`
  - `Gemini 3.1 Pro`
- Exactly one unique `内容题材` terminal path required for archive placement.
- Content-topic fallback request when the first model response lacks an archive branch.
- Structured item timing fields for later performance diagnosis.
- Safer default tagging concurrency:
  - Qwen profiles default to `10`
  - Gemini profiles default to `2`

## Verification Status

The release baseline must pass:

```bash
npm run test:taxonomy-domain
```

The latest pre-release verification target is the full unit and integration suite covering archive, CLI, core records, download, governance, retrieval, spreadsheet, tagging, taxonomy, Web UI, and phase integration tests.

## Security And Local Exclusions

The release intentionally excludes:

- `*.local.json`
- real API keys
- cookies and browser session exports
- OAuth secrets and tokens
- `.cache/`
- `.runtime-state/`
- `.runtime-uploads/`
- `node_modules/`
- downloaded or edited video files
- user spreadsheets
- `视频数据下载缓存/`
- `视频数据采集总表.xlsx`

See `docs/release/V0.2_LOCAL_EXCLUSIONS.md` for the local exclusion policy and `docs/release/V0.2_BASELINE_MANIFEST.md` for the source baseline manifest.

## Known Limits

- V0.2 is a local single-user workflow, not a cloud product.
- The system does not guarantee platform download success, automatic login, anti-risk bypass, or watermark removal.
- Platform download reliability depends on `yt-dlp`, `ffmpeg`, local network conditions, account state, platform policy, and cookie freshness.
- `Numbers` is a compatibility path; full hyperlink behavior is only guaranteed for `xlsx`.
- Gemini preview behavior and rate limits depend on the user project tier and provider availability.
- No remote delivery system, team collaboration model, or full report dashboard is included in this release.
