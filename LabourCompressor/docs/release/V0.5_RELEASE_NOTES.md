# V0.5 Release Notes

## Summary

V0.5 locks the current LabourCompressor baseline around a simplified main workflow and a professional advanced workspace. The release unifies URL spreadsheets and local-media intake, adds managed taxonomy and credential repositories, improves model and platform readiness visibility, and makes task failures reusable through review and resume flows.

## Included Capabilities

- Mainline and advanced Web UI modes sharing one task form and runtime state.
- Three-column wide-screen workspace with responsive one- and two-column fallbacks.
- URL spreadsheet and local-directory intake as equal first-class entry paths.
- Managed internal and external taxonomy repositories with import support.
- Platform credential import, replacement, metadata display, and post-import probing.
- Model-level API readiness summaries without exposing secrets.
- Continuity-first local segmentation using frame-refined PySceneDetect boundaries plus visual, motion, and audio algorithms, with hard `5-60s` computed ranges and preferred `5-30s` ranges.
- Automatic segmentation profiles, boundary-refinement fallback, mechanical continuity fallback, compact diagnostics, precise H.264/AAC clip export, and ProblemClips review queues.
- Compact task status with actionable failures, collapsible complete results, and resumable processing.
- Standard spreadsheet schemas for user input, machine trace data, writeback, and archive records.

## Compatibility And Limits

- The application remains a local, single-user workflow.
- Existing V0.2 and V0.3 spreadsheets and recovery paths remain compatibility inputs.
- Segmentation remains rule-based and depends on local video tooling.
- Download reliability depends on platform policy, credentials, network state, and downloader support.
- Product version V0.5 does not change taxonomy asset versions such as core V0.1, advanced V0.2, or candidate V0.3.
