# One-Click Launcher Design

## Goal

Upgrade the generated macOS `LabourCompressor.app` so a non-technical user can double-click it after receiving the project and reach the local Web UI with minimal command-line work.

## Scope

The launcher remains a local macOS app generated by `scripts/create-macos-app.ts`. It does not become a signed `.pkg`, does not add cloud hosting, and does not change the Web UI pipeline.

## Behavior

On launch, the app locates the project root, prepares a user log directory, and checks whether a LabourCompressor Web UI is already listening on the default port range. If a running instance is found, it opens the browser immediately.

If no instance is running, the launcher verifies first-run prerequisites. Node.js 22+, npm, Homebrew, and Xcode Command Line Tools are manual prerequisites because the existing setup script cannot bootstrap them safely. Missing manual prerequisites produce a macOS dialog with the exact requirement.

For project-local or Homebrew-managed runtime dependencies, the launcher reuses `scripts/setup-macos.sh`. It runs setup when any of these are missing: `node_modules`, `yt-dlp`, `ffmpeg`, Python 3.11, or the two local config files copied from templates. Setup still attempts project-local PySceneDetect installation, but a PyPI/network failure must not prevent the Web UI from opening.

After setup succeeds, the launcher starts `node apps/cli/main.ts serve-web-ui`, waits for `/api/defaults`, writes logs under `~/Library/Logs/LabourCompressor`, and opens the local URL.

## Error Handling

Setup output is appended to the same launcher log. If critical setup or server startup fails, the app shows a dialog pointing at the log file. PySceneDetect setup failures are logged as warnings because the Web UI can still open and report segmentation readiness through preflight.

## Testing

Desktop launcher unit tests assert the generated `launcher.sh` contains the setup detection, manual prerequisite checks, setup invocation, log handling, and unchanged server reuse/open-browser behavior.
