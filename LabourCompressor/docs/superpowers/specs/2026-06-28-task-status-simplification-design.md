# 任务状态模块精简设计

## 目标

将首页“任务状态”从持续占据大面积的明细面板改为紧凑的双层工作台。用户应当无需滚动或横向拖动即可看到任务结论、当前进度和必要操作；完整过程、成功明细和技术信息按需展开。

本次仅调整 Web 展示与交互，不改变任务执行、阶段恢复、结果数据结构或 API 契约。

## 设计原则

- 异常优先：失败项和人工待处理项优先于成功明细。
- 状态驱动：只显示当前状态下可执行的操作，不长期展示禁用按钮。
- 渐进披露：核心状态常显，过程与技术明细折叠。
- 响应式：宽屏双列、窄屏单列，任何内容不得造成页面横向滚动。
- 视觉一致：复用“授权与归档”的边框、圆角、字号和折叠交互。

## 信息架构

### 第一层：核心状态

第一行由两个区域构成：

1. 当前状态：显示任务状态和当前环节。
2. 处理进度：显示 `current / total`、百分比和进度条。

运行中显示“暂停”和“强制停止”；暂停后显示“恢复”和“强制停止”；其他状态不显示无效控制按钮。

### 第二层：上下文与结果摘要

- 当前文件：运行中显示，长文件名省略，完整值通过 `title` 查看。
- 任务上下文：模型和来源模式使用弱化文本显示。
- 平台：仅识别成功且与当前处理有关时显示。
- 结果摘要：显示总数、成功、失败、待处理数量。
- 下一步操作：仅需要用户介入时显示为单行操作提示。

不得继续使用“模型 · 来源 · 平台 · 下一步”拼接成长句。

### 第三层：折叠内容

1. `运行检查与阶段`：合并 Preflight 检查和阶段进度。
2. `失败与待处理`：存在失败或人工待处理项时自动展开，否则不显示。
3. `完整结果`：默认收起，包含全部逐文件结果。
4. `调试与恢复`：合并原始日志、Preflight 原始输出、部分回表和失败 CSV 导出。

## 状态行为

### 未开始

显示“尚未运行任务”。隐藏空进度、空文件、空结果和无意义的占位符。

### 运行中

显示当前环节、当前文件、进度和上下文。只显示“暂停”和“强制停止”。

### 已暂停

“恢复”为主要操作，“强制停止”为危险次级操作。

### 成功完成

显示结果汇总。完整结果保持收起；成功的 Preflight 仅显示一行摘要。

### 存在失败

核心状态使用失败状态样式，自动展开“失败与待处理”。成功项仍收纳在“完整结果”内。

### 需要人工处理

显示一个明确的下一步操作，例如“更新下载凭证”或“进入问题片段复查”。避免在主界面展示故障原因的长段解释。

### Preflight 失败

只直接展示未通过项；通过项放入“查看完整检查”。

## 明细展示规则

- 成功行不重复显示“无”“无需处理”。
- 失败行必须保留文件、失败阶段、原因和下一步。
- 待处理行必须保留文件、当前状态和下一步。
- 结果摘要中的失败数量可用于展开失败项。
- 完整文件列表默认收起，无论任务是否成功。

## 响应式规则

- 宽屏：核心状态和处理进度为两列；上下文和结果摘要占下一整行。
- 中等宽度：核心区域保持两列，操作按钮允许换行。
- 窄屏：所有内容单列，操作按钮使用短文本。
- 网格轨道使用 `minmax(0, 1fr)`，子元素设置 `min-width: 0`。
- 文件名和路径使用省略或自然换行，不得撑宽页面。
- 桌面端完整结果使用四列；窄屏改为逐项信息块。
- 展开内容只允许纵向滚动，不允许页面或模块产生横向滚动。

## 保留、合并与移除

### 保留

- 当前状态、当前环节、进度和当前文件。
- 成功、失败、待处理数量。
- Preflight、阶段进度、逐文件结果、原始日志和恢复操作。

### 合并

- 四张状态卡合并为两个核心区域。
- Preflight 与阶段进度合并为“运行检查与阶段”。
- 调试信息与故障处理合并为“调试与恢复”。
- 结果统计与完整列表改为摘要加折叠明细。

### 移除或隐藏

- 拼接式上下文长句。
- 未开始时的多个 `—`。
- 长期显示的禁用按钮。
- 成功 Preflight 的完整检查列表。
- 成功文件重复的“无”和“无需处理”。

## 验收标准

- 未开始时任务状态模块不显示空卡片和无效按钮。
- 各任务状态只显示可执行操作。
- 成功任务的完整文件列表默认收起。
- 存在失败时失败项自动展开，成功项保持收起。
- Preflight 成功时只显示一行摘要，失败时只展开失败检查。
- 390px、768px、1024px 和常用宽屏视口均无横向滚动。
- 长文件名、长归档路径不撑宽布局。
- 原有暂停、恢复、停止、失败导出和部分回表功能仍可使用。
- Web 单元测试及 `npm run test:taxonomy-domain` 全部通过。
